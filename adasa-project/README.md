# عدسة | Adasa Photography Blog

مشروع مدونة تصوير فوتوغرافي مبني باستخدام React وVite وReact Router DOM، ويستخدم بيانات المقالات المحلية الموجودة في `src/data/posts.json` دون الحاجة إلى Backend أو API.

## المتطلبات
- Node.js (يفضل إصدار LTS حديث)
- npm

## التشغيل محلياً
1. فك ضغط مجلد المشروع.
2. افتح مجلد `adasa-project` في Visual Studio Code.
3. افتح Terminal داخل المجلد.
4. نفّذ الأوامر التالية بالترتيب:

```bash
npm install
npm run dev
```

5. افتح رابط localhost الذي يظهر في الـ Terminal.

## المميزات
- صفحة رئيسية بتصميم متجاوب وأقسام المقالات المميزة والتصنيفات.
- صفحة المدونة مع البحث الفوري والتصفية حسب التصنيف.
- عرض شبكي أو قائمة للمقالات.
- Pagination يعرض 6 مقالات في كل صفحة.
- صفحة تفاصيل ديناميكية لكل مقال باستخدام الـ slug.
- صفحة 404 للمسارات غير الموجودة.
- تبديل الوضع الداكن والفاتح.
- بيانات المقالات محلية في ملف JSON ولا تحتاج إلى API.
